# Privacy Policy

*Last updated: 2026-06-15*

## Summary

state-history-forensic is a local Rust library. It does not collect, transmit, or store any personal data on remote servers.

## Data Access

state-history-forensic is a zero-dependency vocabulary crate — it defines types and traits only. It performs no I/O, reads no files, and accesses no data on its own. Any processing happens in memory on your local machine in the crates that depend on it. Nothing is uploaded anywhere.

## Telemetry

state-history-forensic has **no telemetry**. It makes no network requests of any kind.

## Open Source

state-history-forensic is open source. You can audit every line of code at [github.com/SecurityRonin/state-history-forensic](https://github.com/SecurityRonin/state-history-forensic).
